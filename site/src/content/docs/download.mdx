SwarmCast is free. All files come from the official [SwarmCast releases on GitHub](https://github.com/Lucas-Angelo/swarmcast/releases/latest). The button above picks the right one for this computer. Below are all systems.

**Requirements:** at least 4 GB of memory, 2 processor cores and 10 Mbps of upload. Recommended: 8 GB, 4 cores and 50 Mbps of upload or more. You also need [OBS Studio](https://obsproject.com/) (free).

## Windows

Windows 10 or 11, 64-bit. On the releases page, download the file that ends in **`x64-setup.exe`**.

Then follow [Install on Windows](/swarmcast/install/windows/).

## macOS

macOS 13.5 (Ventura) or newer. There are two files:

- **Mac with an Apple chip** (M1 or newer): the file that ends in **`aarch64.dmg`**.
- **Mac with an Intel chip**: the file that ends in **`x64.dmg`**.

Not sure? Apple menu → **About This Mac**. Then follow [Install on macOS](/swarmcast/install/macos/).

## Linux

- **Ubuntu, Debian, Linux Mint, Pop!_OS:** the file that ends in **`amd64.deb`**.
- **Any other distribution:** the file that ends in **`amd64.AppImage`**.
- ARM computers: the `arm64.deb` or `aarch64.AppImage` files.

Then follow [Install on Linux](/swarmcast/install/linux/).

## Other ways to install

- [Advanced: install with a script](/swarmcast/advanced/script-install/) (installer zip or one command), for advanced users and servers.
- The source code is on [GitHub](https://github.com/Lucas-Angelo/swarmcast).
